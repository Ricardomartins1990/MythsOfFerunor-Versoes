# Myths of Ferunor — versões publicadas

Este repositório contém **apenas os pacotes do jogo** para o launcher oficial atualizar automaticamente.
O código-fonte é privado.

- Pacote Windows: `MythsOfFerunor-<versão>-Windows.zip` + `SHA256SUMS-<versão>.txt` em cada Release.
- Instalador do launcher: `MythsOfFerunor-Launcher-Setup-<versão>.exe`.
- O launcher confere SHA-256, tamanho e `BUILD-INFO.txt` antes de instalar e preserva a instalação anterior.
